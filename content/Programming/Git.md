# Git

## Základní workflow

```bash
git status
git add .
git commit -m "Update notes"
git push
```

### Co příkazy dělají

`git status` ukáže změny.

`git add .` připraví všechny změny v aktuální složce a jejích podsložkách ke commitu.

`git commit` vytvoří nový lokální commit.

`git push` odešle commity na GitHub.
