# C#

## Základy

C# je objektově orientovaný jazyk používaný hlavně na platformě .NET.

## Užitečné věci

### Proměnná

```csharp
int number = 10;
string name = "Hello";
```

### Podmínka

```csharp
if (number > 5)
{
    Console.WriteLine("Bigger than 5");
}
```

### Metoda

```csharp
int Add(int a, int b)
{
    return a + b;
}
```
